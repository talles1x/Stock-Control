# Stock Control

> 🚧 Em desenvolvimento

Sistema de controle de estoque que roda **localmente, sem internet**, pensado para pequenos comércios. O cliente cadastra, visualiza e remove produtos com autonomia, sem depender de servidor.

## Escopo planejado

- Cadastro de produtos
- Visualização do estoque
- Remoção de produtos
- Funcionamento 100% offline, com os dados salvos no próprio computador
